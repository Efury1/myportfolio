# Leaps of Legend: My js13kGames 2026 Entry

## The event

js13kGames is a month long game jam for browser games. The whole game, code and assets, must fit in a 13KB zip file. This year's theme was "Unicorns and Rainbows." The jam runs from mid August to September 13.

## What I built

I made **Leaps of Legend**, a browser based arcade game built in plain HTML, CSS, and JavaScript, with no frameworks or libraries. It fits the theme with a fast paced hop and dodge style of play.

## What I worked on

- Core movement, getting the character to respond cleanly to key presses
- Handling simultaneous key presses so moves don't fight each other or get dropped
- Sprite animation, syncing the visuals to match the movement state
- Keeping the whole build tiny enough to fit the 13KB size limit

## What I learnt

- How to handle key input properly, so two keys pressed at once don't fight each other or get dropped
- How to sync sprite animation to actual movement state, not just a fixed timer
- How to keep code and assets small enough to fit a strict 13KB limit
- General game loop structure, outside my usual SCSS and CMS work
